# WooCommerce Moneybird Amazon Marketplace add-on

This plugin adds extra settings and functionality to the [ExtensionTree.com WooCommerce Moneybird API integration plugin](https://extensiontree.com/woocommerce-moneybird-koppeling/).
The extra functionality allows you to configure the following items separately for WooCommerce orders that were received through Amazon Marketplace:

- Enable/disable automatic invoice generation
- Invoice reference field
- Moneybird workflow
- Document style
- Revenue ledger account
- Always mark invoice as paid?
- Never send invoice?

The add-on is compatible with the following Amazon Marketplace order importers:

- https://www.channable.com/integrations/amazon-marketplace-integration

To use this plugin you first need to have the [WooCommerce Moneybird API plugin](https://extensiontree.com/woocommerce-moneybird-koppeling/) installed and activated.


## Download and installation

Download the latest version of the plugin here:

https://github.com/extensiontree/woocommerce-moneybird-amazon/releases

In WordPress, go to Plugins -> New plugin -> Upload plugin and upload the zip file. Activate the plugin after upload.
The settings page can be found in WooCommerce -> Settings -> Integrations -> Moneybird Amazon Marketplace.
